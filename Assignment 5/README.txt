OVERVIEW

This project contains implementations of four important Artificial Intelligence concepts and algorithms:

1. Adversarial Search Algorithms
2. AI Based Travel Planner
3. Knowledge Graph Implementation
4. Bayesian Network Implementation

The objective of this assignment is to understand how AI techniques are used in game playing, intelligent recommendation systems, knowledge representation, and probabilistic reasoning.

--------------------------------------------------

1. ADVERSARIAL SEARCH ALGORITHMS

This module implements the following algorithms:

• Minimax Search
• Alpha-Beta Pruning
• Heuristic Alpha-Beta Search
• Monte-Carlo Tree Search (MCTS)

Problem Used:
Tic-Tac-Toe Game

Key Idea:
These algorithms are used in decision-making and game-playing AI systems to determine the optimal move.

Features:
• Full Minimax implementation
• Alpha-Beta optimization
• Heuristic evaluation with depth limit
• Monte-Carlo simulations for intelligent move selection
• Test cases included

--------------------------------------------------

2. AI BASED TRAVEL PLANNER

This project implements an intelligent travel planning system using reusable knowledge bases.

Knowledge Bases Used:
• Tourist Places
• Food Recommendation
• Wine/Drink Pairing
• Personalized Tour Planning
• Cost Estimation

Key Idea:
The system recommends places, food, and travel plans based on user interests, travel style, and available time.

Features:
• Personalized recommendations
• Budget estimation
• Attraction filtering
• Food and drink suggestions

--------------------------------------------------

3. KNOWLEDGE GRAPH IMPLEMENTATION

This module demonstrates the creation and querying of a Knowledge Graph.

Features:
• Triple-based representation
• Rule-based inference
• Query system
• DOT file export for visualization

Key Idea:
Knowledge Graphs help represent relationships between entities and support intelligent reasoning.

Tools That Can Be Used:
• Neo4j
• RDFLib
• Apache Jena
• Protégé
• GraphDB

--------------------------------------------------

4. BAYESIAN NETWORK IMPLEMENTATION

This project implements a Bayesian Network for probabilistic reasoning.

Example Used:
Burglary Alarm Problem

Variables:
• Burglary
• Earthquake
• Alarm
• John Calls
• Mary Calls

Key Idea:
Bayesian Networks are used to model uncertainty and perform probabilistic inference.

Features:
• CPT (Conditional Probability Table)
• Exact inference using enumeration
• Probability calculations
